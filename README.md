# EC133 Exam Crammer

Interactive, animated last-night revision for the University of Warwick **EC133 Linear Algebra** exam.

**Live site:** https://colourfulwaterbottle.github.io/EC133/

Single static file (`index.html`), no build step. Open it on a phone or laptop; progress is saved in the browser.

## What it covers

Built from every EC133 past paper 2016-2024, which all share the same five-question structure:

1. Row reduction, rank & nullity (RREF animator)
2. Matrices for linear maps & composition + determinant geometry
3. Eigenvalues, diagonalisation (A = QD Q^T animation) & difference equations
4. Quadratic forms & orthogonal diagonalisation
5. Determinants, elementary matrices & 2x2 geometry
6. Proof templates (linear map, ker/im subspaces, ...)
7. Bases, dimension & linear independence
8. Symmetric & orthogonal matrices

Plus a phone-friendly cheat sheet and a timed mock exam using real past-paper questions.

## Tech

Plain HTML/CSS/JS. MathJax (SVG output) and Google Fonts via CDN. No framework, no dependencies to install.
